objects; they do not introduce a new sampler or a new posterior target.
- Algorithm 3: restore the missing source index in (A^j)^2.
- Algorithm 4: label the state-factor update r^(k), consistent with Algorithm

  observation-time subscripts or the scale-prior hyperparameter names.

  specified likelihood.

  forecast-state dimension p_t and state that inactive blocks are removed
  by restricting states, selectors, transitions and covariance matrices.

Reproduction and active-document integration
-------------------------------------------
Use the bounded editorial command from the article root:

    python3 -B scripts/refresh_editorial_revision.py --check

This checks both table presentation and the long-cycle axis annotation against
the retained inputs. It writes no tracked source or output files. The figure
check renders temporary comparison images to verify the retained annotation
and plotted layers. It does not repeat model fitting or predictive scoring.

To reproduce only these editorial outputs after a reviewed change to their
explicit presentation contracts, omit --check:

    python3 -B scripts/refresh_editorial_revision.py

The table source contract pins all 15 original table SHA256 values and lists
each permitted wording substitution. Generation checks every source and every
statistical table entry before writing the new presentation files. It cannot
silently adopt changed numerical inputs. The figure uses the compact retained
summary and verifies that all pixels outside the y-axis annotation are unchanged.
These commands do not call the general generated-asset refresh, import new
model outputs, or change the original protected table and figure files.

The active manuscript includes the presentation tables directly, and all 16
table entries in MANUSCRIPT_ASSET_MANIFEST.json point to those 15 included files.
The review builder follows actual input/include dependencies recursively;
commented and unused companion fragments cannot satisfy active-document checks.
Its before/after source hashes include every reachable presentation table and
the active long-cycle figure. Missing or external TeX includes are rejected.

Focused integration and statistical-preservation checks:

    python3 -B -m unittest discover -s tests -p test_editorial_revision.py
    python3 -B -m unittest discover -s tests -p test_editorial_integration.py

For a fresh PDF proof, choose an output directory that does not yet exist:

    python3 -B scripts/build_manuscript_review.py --output-dir /tmp/editorial_review_fresh --jobname editorial_review

The proof report records source hashes, reference stability, bibliography
warnings and the PDF identity. Main-text runtime remains approximately two
hours for the seven fitted probabilities; hardware and timing-scope details
are given in the computational appendix (app:computationtime).
